# Game Hotkey Overlay for Android

A persistent floating overlay controller designed for Android games and web-based games (e.g. running in Brave / Chrome). It provides on-screen access to PC game hotkeys (`Shift + O`, `Shift + D`, `Shift + R`, `ESC`) and cheat/console command execution helpers without disappearing when the screen is tapped.

## Features
- **Persistent Floating Bubble (`🎮`)**: Stays on top of games/browsers and never auto-collapses on tap.
- **Draggable & Minimizable**: Place anywhere along the screen edge; collapse to bubble or expand to panel.
- **Hotkeys**: Direct triggers for developer consoles and menus (`Shift + O`, `Shift + D`, etc.).
- **Cheat Helper**: Input cheat commands, copy one-click JS console injection snippets.

## Download & Install APK
Download the compiled `GameHotkeyOverlay.apk` from the Releases section or directly from this repository, then install it on your device and grant the "Display over other apps" permission.
